# 工程解读与原 CNN 的关系

## 结论

这个实验值得作为原项目的**传统方法基线与诊断证据**保存；不建议替换 CNN，也没有验证任何自动分流、集成或上线方案。

验证集（不是测试集）从 34 个固定配置中选出 PCA16 + 3NN。它在同一 1616 张测试晶圆上，相对原 CNN 的 Macro F1 增加 0.0866，按 lot 的配对 bootstrap 95% 区间为 [0.0596, 0.1122]，平衡准确率增加 3.25 个百分点。相对不降维的同一 3NN，准确率增加 12.50 个百分点。这支持“降维可改善这个有限样本下的最近邻分类器”的结论。

| 相同测试子集 | PCA16+3NN | 原 CNN |
|---|---:|---:|
| Accuracy | 39.91% | 35.95% |
| Balanced Accuracy | 41.82% | 38.57% |
| Macro F1 | 0.4347 | 0.3481 |
| Center recall | 45.73% | 5.03% |
| Scratch recall | 38.58% | 2.54% |
| Edge-Ring recall | 38.19% | 61.31% |
| none recall | 17.59% | 100.00% |

## 可参考的工程发现

1. Center、Loc、Scratch 的差距表明，这些类别并非完全无法从当前输入中区分；一个保留位置结构的简单基线在当前基准上比已有 CNN 更有效。这是调查 CNN 空间表征、训练失衡与泛化的线索，不是对具体原因的证明。
2. PCA16 将 4096 个像素压缩到 16 个系数，有利于构建紧凑的检索/分类表示；不能仅用维数比宣称整体推理加速。保存的模型同时包含投影矩阵及邻居数据。
3. 各类收益并不一致。新基线把很多正常晶圆当成缺陷，若直接替换会增加大量误报；没有验证其与 CNN 的融合或人工复核路由能改善端到端成本。
4. 最近类均值的改善很小，说明降维收益依赖分类器，不是增加 PCA 就普遍有效。

## 不应忽略的限制

- 候选的验证 Macro F1 为 0.7990，测试为 0.4347。大幅下降说明泛化仍然不足。批次输入分布变化、类别条件分布变化和验证集代表性不足都是待查假设，不能凭本实验确定原因。
- 训练/验证/测试均保留原项目的批次边界，但只使用按类别限额的子集。原 CNN 训练数据更多，不是等训练预算的架构比较。
- 测试集已被原项目观察，本次是回顾性基准。新模型的超参数仅在验证数据上选择，并未根据测试结果调整。
- 对最终输入的完全重复仅在本次抽样子集中去除；没有重新审计或训练原 CNN 的完整数据。
- 测试类别比例改变，因此这里的 CNN Accuracy 35.95% 不能与其完整测试集 94.38% 比较为“退化”。两个数字来自不同类别比例和样本。
- bootstrap 反映当前抽样/批次不确定性，不涵盖重训随机性或外部工厂变化。
- 固定的 64×64 缩放仍可能损失细缺陷；没有在看过测试分数后改尺寸。
- 原 CNN 未做同条件推理计时，因此不声称传统模型比 CNN 快。

## 项目纳入范围

纳入独立 `experiments/dimensionality_baseline` 实验目录和 README 索引，保留原 CNN 的源代码、权重、清单和历史评价。它是对比基线，不是生产模型更新。

如果后续继续工程研究，应预先保留新的验证批次，再比较针对少数类/空间信息的改进；不能反复在当前测试集上选择修改。
